## 🚀 Quick Setup

```bash
# 1. Create a new Vite React TypeScript project
npm create vite@latest nexaerp -- --template react-ts
cd nexaerp

# 2. Copy all files from this ZIP into the project, matching the folder structure

# 3. Install dependencies
npm install

# 4. Install additional dependencies
npm install jszip recharts react-router-dom
npm install -D tailwindcss postcss autoprefixer tailwindcss-animate

# 5. Start the dev server
npm run dev
```

## 📦 Key Features

- **Glassmorphism UI** — Dark/Light mode with CSS variable auto-adapt
- **Role-Based Access** — Owner (full) / Manager (ops) / Staff (data entry)
- **Multi-step Registration** — Details → OTP → Category → CSV Upload
- **Working Buttons** — Every button has real functionality
- **CSV Import/Export** — Products, customers, expenses, payroll
- **WhatsApp Integration** — Direct wa.me links from all modules
- **AI Chatbot** — ERP-aware UniversalAI with quick prompts
- **Barcode Scanner** — Camera scan modal with product detection
- **Global Search** — ⌘K searches products, customers, staff, leads
- **Invoice Modal** — Print, WhatsApp share, CSV download
- **Add Staff with Login** — Creates login credentials from staff form
